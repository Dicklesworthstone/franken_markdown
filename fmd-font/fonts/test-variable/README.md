# FmdTestVF — project-authored OFL variable-font fixture

`FmdTestVF.ttf` is a **tiny synthetic OpenType variable font** authored in this
repository for parser tests (`gk3v.1`). It is not a design face.

## Provenance

- **Author:** franken_markdown test fixture, generated by the deterministic
  sfnt builder in `fmd-font/src/lib.rs` (`synthetic_font_tests::fmd_test_vf_bytes`).
- **License:** SIL Open Font License 1.1 (see `OFL.txt`). No Reserved Font Name.
- **Why it exists:** `Font::parse` requires a complete sfnt (`head`/`maxp`/
  `hhea`/`hmtx`/`cmap`) even when the test target is `fvar`/`avar`. Vendoring a
  multi-megabyte retail VF would dwarf the crate; this fixture is a few hundred
  bytes and encodes exactly the tables the tests assert.

## Contents

| Table | Role |
| --- | --- |
| `head` / `maxp` / `hhea` / `hmtx` / `cmap` | Minimum parseable static skeleton (1 glyph) |
| `fvar` | One `wght` axis, user space 100 / 400 / 900, two named instances (Regular=400, Bold=700) with PostScript name IDs |
| `avar` | Identity map `(-1,-1), (0,0), (1,1)` |

`FmdTestVF.ttf` has **no** `glyf`/`gvar`. Outline instancing, mixed-weight PDF,
and cmap-shared bbox L∞ comparisons use `fmd_font::variable_triangle_fixture()`
(built in `fmd-font/src/gvar.rs`). Dump it for CLI e2e with:

```bash
FMD_DUMP_TRIANGLE_VF=/tmp/FmdTriangleVF.ttf cargo test -p fmd-font dump_triangle_vf_when_requested -- --exact
```

The method and size report live in [`docs/VARIABLE_FONTS.md`](../../../docs/VARIABLE_FONTS.md).

Regenerate (does not overwrite this directory; copies from `/tmp`):

```bash
FMD_DUMP_TEST_VF=1 cargo test -p fmd-font fmd_test_vf_fixture_round_trip -- --exact
cp /tmp/FmdTestVF.ttf fmd-font/fonts/test-variable/FmdTestVF.ttf
```

## Independent packed-delta fixture

`FmdPackedDeltasVF.ttf` is a 1,660-byte original test font, released under the
same OFL 1.1 license and copyright as `FmdTestVF.ttf`. It contains an empty
`.notdef`, a triangle at `A`, and one `wght` variation. The variation mixes
zero runs, signed byte runs, signed word runs, X/Y deltas, and a right-phantom
advance adjustment. Unlike the in-crate synthetic builders, FontTools encodes
its complete `glyf`/`gvar` tables independently. This catches an incorrect
packed-delta interpretation even if a handwritten fixture repeats that error.

The integration regression checks every triangle vertex and both horizontal
metrics at weights 400, 650, and 900 against the FontTools instancer. Regenerate
and verify with FontTools 4.61.1:

```bash
python fmd-font/fonts/test-variable/generate_packed_deltas.py
```

FontTools is only needed to regenerate the fixture; normal Rust tests read the
committed font without Python or third-party font libraries.
