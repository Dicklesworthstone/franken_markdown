Publish a Markdown book

Arrange chapters and export one merged PDF, EPUB, or linked HTML-site ZIP using the Rust book engine. Rendering runs in a cancellable worker. Your source and images are never uploaded.

Save your work before leaving. Use the optional local library below, or prepare a source project and click Download. Both retain chapter source, order, paths, and settings, but deliberately exclude images and permissions. Reopening requires authorizing images again.

Local book library and recovery

Save a named copy in this browser, then optionally enable autosave. Nothing is saved automatically before you opt in. Local data is unencrypted, shared by tabs on this origin, and may be evicted or cleared; download source projects as backups. Images and file permissions are never stored.

Autosave waits for text composition to finish. Invalid paths or settings, storage failures, and conflicting edits pause it without replacing the last saved revision. Reopening, importing a source project, or suspending the page turns it off. Only an acknowledged transaction counts as saved.

Up to 32 books and five recent revisions per book, within a 128 MiB source-JSON budget. Saving may prune that book’s oldest revisions to fit; other books are never silently evicted. Opening an old revision does not overwrite the latest saved one. Save creates a new revision.
