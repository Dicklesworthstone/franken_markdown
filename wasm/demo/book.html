Single-document editor · HTML/PDF demo

Publish a Markdown book

Arrange chapters and export one merged PDF, EPUB, or linked HTML-site ZIP using the Rust book engine. Rendering runs in a cancellable worker. Your source and images are never uploaded.

Save your work before leaving. Use the optional local library below, or prepare a source project and click Download. Both retain chapter and include-only source, roles, order, paths, and settings, but deliberately exclude images and permissions. Reopening requires authorizing images again.

Local book library and recovery

Save a named copy in this browser, then optionally enable autosave. Nothing is saved automatically before you opt in. Local data is unencrypted, shared by tabs on this origin, and may be evicted or cleared; download source projects as backups. Images and file permissions are never stored.

Autosave waits for text composition to finish. Invalid paths or settings, storage failures, and conflicting edits pause it without replacing the last saved revision. Reopening, importing a source project, or suspending the page turns it off. Only an acknowledged transaction counts as saved.

Up to 32 books and five recent revisions per book, within a 128 MiB source-JSON budget. Saving may prune that book’s oldest revisions to fit; other books are never silently evicted. Opening an old revision does not overwrite the latest saved one. Save creates a new revision.

1. Add chapters, shared sources and images

Use .md or .markdown chapters and PNG/JPEG/SVG images. Folder import retains paths beneath the selected root; other extensions are ignored and counted. Import appends atomically and refuses duplicate paths. File-picker order is not guaranteed to match reading order: arrange the list below.

Include-only files are editable and saved with your book, but never become standalone chapters. Choose text snippets or code files here, not binary assets. All selected files must be UTF-8. Use the source-role control below to turn an imported Markdown chapter into a shared snippet. Nothing is fetched implicitly.

Limits: 128 chapters and 128 include-only files, 4 MiB per source and 16 MiB combined source plus paths; 128 images, 8 MiB each and 32 MiB total. Export has a 128 MiB output ceiling and a two-minute worker deadline.

2. Arrange and edit

For example, guide/start.md. Links such as ../end.md and relative image references resolve from this path. Renaming does not rewrite links; update references yourself.

Only numbered chapters get pages or EPUB spine entries. Include a shared source with {{#include ../parts/shared.md}}, optionally with a named region or line selector. Includes resolve relative to the file containing each directive; links and images in inserted text resolve from the publishing chapter. Renames and removals do not rewrite references.
