# Deterministic shaping fixture

`FmdShaping.ttf` is an original SIL OFL 1.1 test face, generated by
`scripts/font-oracles/generate-shaping-fixture.py` using FontTools 4.65.0.
Its deliberately simple outlines make glyph selection and placement easy to
inspect. `features.fea` records the OpenType rules for Latin ligatures/pairs,
combining marks, Arabic joining forms, required lam-alef ligatures, and stacked
marks. No system fonts are used.

`harfbuzz-reference.tsv` was produced independently by uharfbuzz 0.56.1 /
HarfBuzz 14.4.0. Each row contains script, logical text, and glyph records:
`gid, UTF8_start, UTF8_end, x_advance, y_advance, x_offset, y_offset`.
The corpus exercises both directions, mark attachment, marks separated by
bases, stacked marks, joining breaks, and ligature clusters. Regenerate with
`scripts/font-oracles/generate-references.py`.

These fixtures prove the documented bounded API, not universal Arabic shaping.
Contextual lookups, cursive attachment, variation positioning, bidi
segmentation, and other unsupported mechanisms must report typed refusals.
